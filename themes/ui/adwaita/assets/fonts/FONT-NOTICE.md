# Adwaita fonts

This theme package includes Adwaita Sans and Adwaita Mono.

- Upstream: GNOME `adwaita-fonts`.
- Adwaita Sans is based on Inter; Adwaita Mono is based on Iosevka and is
  customized to match Inter.
- Copyright and licence details: `LICENSE.txt` (SIL Open Font License 1.1).
- These font files are distributed with this theme package only. They are not
  part of the Nota application bundle.
