# IBM Plex font notice

This theme bundles a subset of the IBM Plex typeface family for offline use.

## Sources

- IBM Plex Sans SC: `@ibm/plex-sans-sc@1.1.0`
  - Upstream: https://github.com/IBM/plex
  - Package: https://www.npmjs.com/package/@ibm/plex-sans-sc
- IBM Plex Mono: `@ibm/plex-mono@2.5.0`
  - Upstream: https://github.com/IBM/plex
  - Package: https://www.npmjs.com/package/@ibm/plex-mono

## Included files

- `IBMPlexSansSC-Regular.woff2`
- `IBMPlexSansSC-SemiBold.woff2`
- `IBMPlexSansSC-Bold.woff2`
- `IBMPlexMono-Regular.woff2`
