# CDE Solaris document theme

This theme pairs with the CDE Solaris interface theme. It keeps the square,
bitmap-typeset character of CDE and applies the Solaris 10 Crimson palette:
`#AEB2C3` for the writing surface and `#B24D7A` for emphasis and rules.

Install the directory from **Settings → Document Themes → Open…**, then select
**CDE Solaris** from the theme menu.
