# Vellum

Vellum is a warm, manuscript-like document theme. Latin text is set in
**Special Elite**; Chinese text falls through to **Huiwen Mincho GBK**. The
theme uses a narrow writing measure, modest first-line indents, restrained
rules, and a rubric-red accent.

# Vellum（中文）

Vellum 是一套暖色手稿感的文档主题。西文使用 **Special Elite**，中文回落到
**汇文明朝体 GBK**。版面采用较窄的阅读列、克制的首行缩进、细线与朱红色强调，
适合长篇笔记、草稿与书信体排版。

字体和许可只随本主题包分发，不进入 Nota 安装包，也不同步到软件“关于”页。
