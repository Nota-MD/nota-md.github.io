# LaTeX theme fonts

The typography uses New Computer Modern (Serif, Sans and Mono), the family
used by the LaTeXTypora theme.

- The upstream LaTeXTypora theme is Apache-2.0; its notice is retained in
  `THEME-APACHE-2.0.txt`.
- Additional upstream attribution is retained in `THIRD-PARTY-NOTICES.md`.
- These font files are distributed with the LaTeX document theme package
  only. They are not part of the Nota application bundle or its About credits.
