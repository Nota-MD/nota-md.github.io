# GitHub Dark

Official Nota document theme based on
[`sindresorhus/github-markdown-css`](https://github.com/sindresorhus/github-markdown-css).

- Upstream version: `5.9.0`
- Upstream commit: `7f38dcb9054bc5d860fac65291f5c98fef47932c`
- Source stylesheet: `github-markdown-dark.css`
- License: MIT; the complete upstream license is in [`LICENSE`](LICENSE)

The upstream `.markdown-body` root is mapped to Nota's documented `#write` root so the theme can
be installed through Nota's normal document-theme pipeline. Nota-specific
document tokens are projected onto GitHub's dark palette. The remaining
upstream rules are retained.
