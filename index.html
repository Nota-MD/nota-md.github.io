The essentials, done well

A writing surface, not a preview workflow.

01

Formatting in place

Headings, emphasis, lists, quotes, code, formulas and diagrams appear where you type.

02

Files stay plain

Every document is saved as standard Markdown. No database and no private document layer.

03

A complete workspace

Tabs, folder tree, outline, autosave, external-change detection and writing modes belong together.

04

Extend with Lua

Install only the capabilities you need. Official AI, Git, presentation and statistics extensions are separate.

05

Two independent theme axes

Change the application shell and the document independently. Themes can bring their own CSS, icons and fonts.

06

Native desktop delivery

Packages for Linux and Windows are built from one Rust and React codebase.

Interface and document themes

Yaru by default. Anything by design.

Nota separates the application shell from the writing surface. Interface themes control controls, spacing, icons and fonts. Document themes control the page without leaking into the workspace.
