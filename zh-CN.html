获取 Nota

Nota 是一款本地优先的极简 Markdown 编辑器。

打开文件就开始写。格式在输入时出现，随后退回到安静的页面里； 不需要账号，也没有专有数据库。

Nota 已经可以开始写作 下载适用于 Linux 或 Windows 的最新版本。 下载 带上一套桌面主题 把可安装的 GNOME/GTK 或 KDE 主题转换成 Nota 主题。 主题转换器

Debian · RPM · AppImage · Windows · 本地文件

坐下来，开始写

格式就在文字里，
不需要离开页面。

标题、强调、引用和代码都在输入时直接成形。文字仍然是普通的 Markdown， 随时可以交给任何工具继续处理。

为桌面而生

熟悉的地方更顺手，
其余时候保持安静。

Nota 以原生窗口运行，直接读写本地文件；紧凑的 GNOME 风格工作台， 也可以换上一套与桌面相配的主题。

  • 原生窗口与直接文件访问
  • 键盘优先，界面不堆叠多余控件
  • 界面与文档主题只由普通 CSS 组成

主题工具

把桌面主题带到 Nota。

拖入可安装的 GNOME/GTK 或 KDE 主题包。转换器在本地读取配色和几何参数， 生成可以直接导入 Nota 的界面主题目录。
