# nota-md.github.io

Static website for [Nota](https://github.com/Nota-MD/Nota).

The site uses a deliberately small stack: semantic HTML, one stylesheet and one
short script for the color-theme control. The visual system follows Nota's Yaru
interface theme and uses the Ubuntu Sans and Ubuntu Mono font families.

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Languages

- `index.html` — English
- `zh-CN.html` — Simplified Chinese

Keep navigation, release links and screenshots synchronized between both pages.
